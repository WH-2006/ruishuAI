1平台是什么

睿枢AI（coral-gpu.com）是一个企业级 AI 基础设施平台，核心业务有两大块：

① 大模型 API 聚合服务

把 DeepSeek、Qwen（通义千问）、Kimi、GLM（智谱）、MiniMax、 等国内主流大模型，以及生图、语音、嵌入、重排序模型，统一聚合到一个平台，通过一套统一的 OpenAI 兼容接口对外提供服务：

  • 一站式调用所有大模型：不用分别注册十几个厂商账号，一个 API Key 调用全部模型
  • 业务代码零修改迁移：接口完全兼容 OpenAI 格式，已有项目只需替换 base_url 和 api_key 两个参数
  • 按量付费，价格优惠：按实际消耗的 Token 计费,部分模型相比官网价格有明显折扣
  • 支持 Agent 开发工具：可直接接入 Claude Code、Codex、OpenCode 等编程助手

② GPU 算力租赁

提供 RTX 4090、A800、H20、昇腾 910B 等 GPU 云实例、裸金属与AI 工作站，覆盖开发推理、模型微调（LoRA / SFT / DPO / RLHF）、私有化部署全场景：

  • 按小时 / 包月 / 裸金属三种交付方式，秒级计费弹性扩缩
  • 预装 PyTorch、TensorFlow、vLLM 等环境镜像，开机即用
  • 99.9% 平台可用性 SLA、数据三重备份 · 异地容灾
💡
什么是 OpenAI 兼容接口？
OpenAI 的接口格式是行业事实标准。只要一个平台"兼容 OpenAI"，就意味着你可以用 OpenAI 官方的 SDK、以及市面上几乎所有支持"自定义 API 地址"的软件（如 Cherry Studio、LobeChat、沉浸式翻译等）来调用它——这就是聚合平台最大的价值。

2注册与登录

打开官网→ 点击「登录」→ 手机号 + 验证码注册→ 进入控制台

2.1 注册账号

  1. 浏览器打开官网 https://www.coral-gpu.com/
  2. 点击右上角「登录」按钮，弹出登录/注册对话框
  3. 切换到「注册」标签，填写：
    • 手机号：输入你的手机号
    • 验证码：点击「发送验证码」，把短信收到的验证码填入
    • 密码：设置密码（至少 8 位）
  4. 勾选同意《服务条款》和《隐私政策》，点击注册

2.2 登录

已注册用户直接在登录框输入手机号 + 密码登录；忘记密码可点击「忘记密码？」，通过手机验证码重置。勾选「保持登录」后一段时间内无需重复登录。

💡
登录成功后会自动进入控制台概览页。如果看到「先完成账号登录，个人账户、钱包和 API 密钥才会生效」的提示，说明还没登录，先登录再操作。

4快速上手三步走

这是控制台概览页官方引导的三个步骤，也是使用本平台最核心的流程：

1

创建 API 密钥

在「API 密钥」页面新建一把密钥，它是调用接口的身份凭证

2

充值额度

在「钱包」页面充值，余额不足接口会返回错误

3

发送首个请求

用 OpenAI 兼容接口发起第一次对话，跑通全流程

第一步：创建 API 密钥（API Key）

  1. 登录后进入控制台，点击左侧导航「API 密钥」
  2. 点击「新建 API 密钥」按钮（新用户会有一个默认key）
  3. 创建成功后，立即复制并妥善保存密钥（形如 sk-xxxxxxxx）
🚨
密钥安全须知：API Key 等同于你账户的支付凭证，谁拿到密钥谁就能消耗你的余额。不要把完整密钥写进前端页面、公开仓库、截图或日志中。如果怀疑泄露，立即到「API 密钥」页删除旧密钥并新建。

第二步：充值额度

  1. 点击左侧导航「钱包」，查看当前余额
  2. 点击充值，选择金额，完成付款
  3. 充值到账后即可开始调用。后续可在「概览」页随时查看剩余额度
⚠️
余额不足时接口会返回 insufficient_user_quota 错误。新手建议先小额充值测试，确认调用正常后再按需补充。

第三步：发送首个请求

最简单的方式是用 curl（Windows 10+ / macOS / Linux 均自带）。打开终端，粘贴以下命令并替换密钥：

bash
curl -X POST "https://www.coral-gpu.com:3000/v1/chat/completions" \
  -H "Authorization: Bearer sk-替换为你的API密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-pro",
    "messages": [
      { "role": "user", "content": "你好，请用一句话介绍睿枢AI" }
    ],
    "stream": false
  }'

如果返回了类似下面的 JSON（包含 choices 和模型回复内容），恭喜你——调用成功！🎉

json
{
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "你好！睿枢AI是一个企业级AI基础设施平台……"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 45,
    "total_tokens": 57
  }
}
💡
首次调用建议选择便宜的模型练手，例如 DeepSeek-V4-Flash（低价）。模型 ID 一定要用模型广场里展示的完整 ID，不能只写展示名。

6.2 先测试连通性：查看可用模型

调用模型列表接口，验证 API Key、Base URL 和网络是否都正常：

bash
curl "https://www.coral-gpu.com:3000/v1/models" \
  -H "Authorization: Bearer sk-替换为你的API密钥"

返回 JSON 里会列出当前可调用的所有模型 ID —— 这些 ID 就是可以填进 "model" 字段的值。

6.3 Python 调用（推荐）

平台兼容 OpenAI 官方 SDK。先安装 SDK（需要 Python 3.7.1+）：

bash
pip install --upgrade openai

然后把 OpenAI 示例中的 base_url 和 api_key 换成本平台的即可，其余代码零修改：

python
from openai import OpenAI

client = OpenAI(
    api_key="sk-替换为你的API密钥",
    base_url="https://www.coral-gpu.com:3000/v1",
)

response = client.chat.completions.create(
    model="deepseek-v4-pro",
    messages=[
        {"role": "system", "content": "你是一位耐心的中文助手"},
        {"role": "user", "content": "用三点说明什么是API"},
    ],
)

print(response.choices[0].message.content)
print(response.usage)  # 本次请求消耗的 Token 数

6.4 Node.js 调用

import OpenAI from "openai";

7进阶：流式输出与多轮对话

7.1 流式输出（Streaming）

把 stream 设为 true，模型会边生成边返回，大幅降低"首字等待时间"，适合聊天应用：

python
stream = client.chat.completions.create(
    model="deepseek-v4-pro",
    messages=[{"role": "user", "content": "写一首关于秋天的短诗"}],
    stream=True,
)

for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)

7.2 多轮对话

API 本身"没有记忆"，多轮对话需要把历史消息一起发送——每轮都把之前的问答追加进 messages 数组：

python
messages = [
    {"role": "system", "content": "你是一位资深架构师"},
    {"role": "user",   "content": "如何为AI聚合平台设计限流？"},
    {"role": "assistant", "content": "可以从令牌桶算法入手……"},  # 历史回复
    {"role": "user",   "content": "展开讲讲令牌桶的实现"},              # 新问题
]
response = client.chat.completions.create(
    model="deepseek-v4-pro", messages=messages
)

9计费与额度说明

9.1 什么是 Token？

Token 是大模型处理文本的最小单位——对中文而言，1 个汉字 ≈ 0.5~1 个 Token，1 个英文单词 ≈ 1~2 个 Token。计费公式：

text
消耗金额 = 输入Token数 × 输入单价 + 输出Token数 × 输出单价
（部分模型另有缓存命中价，缓存命中部分通常大幅优惠）

9.2 账单哪里看？

  • 单次请求消耗：API 响应中的 usage 字段（prompt_tokens / completion_tokens）
  • 历史明细：控制台 → 「使用日志」，可逐条核对每次请求的模型、状态、延迟和费用
  • 余额与趋势：控制台 → 「概览」（本月消费、累计 Tokens、请求次数、成功率）/「数据看板」/「钱包」

9.3 省钱技巧

  • 能用 Flash / 小尺寸模型解决的，不用旗舰模型（价差可达数十倍）
  • 合理设置 max_tokens，避免意外超长输出
  • 重复的长提示词（如系统提示、文档背景）利用提示缓存，缓存命中部分按优惠价计费
  • 多轮对话别无限累积历史消息，适时裁剪，输入 Token 同样计费
  • 先用免费模型（如 Qwen/Qwen3.5-4B）完成开发和调试，上线再切换付费模型

10安全须知

  • 密钥即钱包：API Key 可直接消耗账户余额，绝不外泄、不发群、不进代码仓库
  • 用环境变量存密钥：程序中通过 os.environ / process.env 读取，不要硬编码
  • 按需选择：在「API 密钥」页为不同环境单独建 Key，按需选择不同 Key
  • 定期轮换：删除不用的旧密钥，疑似泄露立即作废重建
  • 敏感数据：业务数据含个人隐私或商业机密时，先了解平台数据策略再上量（平台提供数据三重备份 · 异地容灾）
  • 谨防钓鱼：认准官方域名 www.coral-gpu.com，客服只通过控制台「在线客服」入口联系

11常见问题 FAQ

调用报错（来自官方文档「常见错误」表）

返回 401 或 API Key 无效

检查 Header 是否为 Authorization: Bearer sk-...，不要漏掉 Bearer。同时确认密钥未在控制台被删除或重置。

返回 404

确认 Base URL 末尾是 /v1，即 https://www.coral-gpu.com:3000/v1，接口路径是 /chat/completions。少了或多了斜杠都会 404。

返回 400 模型不存在

使用模型广场里展示的完整模型 ID，不要只写展示名。可先调 GET /v1/models 核对可用 ID。

返回 insufficient_user_quota（余额不足）

账户余额不够了。充值后重试，或选择价格更低、输出更短的模型（如免费的 Qwen/Qwen3.5-4B）。

账户与计费

为什么余额和 Token 数不能直接换算？

不同模型的输入、输出及缓存计费倍率不同，部分模型美元计价、部分人民币计价，账户统一折算为额度结算。想知道某次请求花了多少，去「使用日志」看明细最准确（含时间、模型、状态、延迟、费用）。

额度消耗看起来比预期快？

长上下文、推理模型（输出中含思考过程）和高输出请求都会显著增加消耗。在「使用日志」中核对每次请求的 Token 明细即可定位原因。

其他

浏览器打开 :3000 地址显示 forbidden？

正常现象。该端口只开放 /v1/ 下的模型 API，供程序调用，不支持网页浏览。日常操作请访问官网主域名。

遇到文档没覆盖的问题怎么办？

① 查看控制台「使用日志」中的错误详情；② 访问平台文档中心（docs.html）查阅「首次调用 API」等官方文档；③ 通过控制台左侧「在线客服」咨询。
